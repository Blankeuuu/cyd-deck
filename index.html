CYD-DECK Web Installer

Install or update your ESP32 dock firmware directly from the browser

Your browser does not support the Web Serial API. Please use Google Chrome, Microsoft Edge, or Brave on a desktop PC.
ESP32-2432S028R (CYD) · ST7789 320x240
Firmware 1.3.0 · LVGL 9.3 · HH:mm Dock Clock · USB Transport

Installation Steps:

  1. Connect your CYD ESP32-2432S028R board to your computer via micro-USB (ensure the cable supports data, not power only).
  2. Click the Install CYD-DECK button above.
  3. In the browser dialog, select your board's serial port (e.g. USB-SERIAL CH340 or CP2102) and click Connect.
  4. Select Install CYD-DECK to flash the firmware.
  5. Wait for the process to complete (~30 to 45 seconds). The board will automatically reboot into the CYD-DECK interface.
