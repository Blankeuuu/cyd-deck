Twoja przeglądarka nie obsługuje interfejsu Web Serial. Użyj Google Chrome, Microsoft Edge lub Brave na komputerze PC.

Firmware 1.3.0 · LVGL 9.3 · Zegar HH:mm · Szybki transport USB

Instrukcja instalacji krok po kroku:

  1. Podłącz płytkę CYD ESP32-2432S028R do komputera za pomocą przewodu USB (upewnij się, że kabel przesyła dane).
  2. Kliknij przycisk ⚡ Zainstaluj CYD-DECK powyżej.
  3. W wyskakującym oknie przeglądarki wybierz port szeregowy płytki (np. USB-SERIAL CH340 lub CP2102) i kliknij Połącz (Connect).
  4. Wybierz Install CYD-DECK (aktualizacja zachowująca Wi-Fi i parowanie) lub opcję wyczyszczenia pamięci flash przy pierwszym uruchomieniu.
  5. Poczekaj na zakończenie procesu (ok. 30–45 sekund). Płytka automatycznie uruchomi się ponownie z nowym interfejsem!
