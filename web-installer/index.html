CYD-DECK

Install the ESP32-2432S028R firmware directly from your browser.

  1. Use Google Chrome, Microsoft Edge, or Brave on desktop.
  2. Connect the CYD board (ESP32-2432S028R ST7789) with a USB data cable.
  3. Close the Windows Agent or any serial monitor using the port.
  4. Click Install Firmware and select the ESP32 serial port (e.g. CH340 or CP2102).

This browser does not support Web Serial. Use Chrome, Edge, or Brave on desktop.

Web flashing requires HTTPS or localhost.
Looking for the PC software? Download the Windows Agent 1.3.0 Setup or visit the CYD-DECK repository.
