# 0001. Rozdzielenie Desktop Appearance i Display Appearance oraz ochrona kontrastu TFT

 Rozdzieliliśmy dotychczasowy wspólny model wyglądu (`appearance`) na dwa niezależne konteksty: `desktopAppearance` (przechowywany wyłącznie lokalnie dla okna **Windows Agent**) oraz `appearance` (**Display Appearance**, synchronizowany przez protokół `device.settings` wyłącznie do **CYD Display**). Dodatkowo po stronie firmware **CYD Display** w trybie ciemnym wprowadziliśmy funkcję sanityzacji tła (`sanitizeCydBackground`), która nakłada warstwę przyciemniającą (*dark-overlay*) na kolory tła o wysokiej luminancji (> 42). Zapobiega to przypadkowemu zepsuciu czytelności białych etykiet na matrycy TFT ST7789 oraz niezamierzonej zmianie motywu aplikacji desktopowej podczas dostosowywania ekranu fizycznego urządzenia.
