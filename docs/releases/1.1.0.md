# CYD-DECK 1.1.0

## Instalacja Windows

Pobierz CYD-DECK-Setup-1.1.0-win-x64.exe z wydania GitHub. Instalator dla bieżącego użytkownika zawiera runtime.NET, bibliotekę obrazów i zależności — osobna instalacja.NET nie jest wymagana. Domyślny katalog: %LOCALAPPDATA%\Programs\CYD-DECK. Tworzy skrót w menu Start; skrót pulpitu jest opcjonalny. Odinstalowanie zachowuje konfigurację, parowanie i cache. Przed ręczną aktualizacją paczki portable zamknij Agenta z menu zasobnika. Installer nie jest podpisany certyfikatem code signing.

Alternatywa: wypakuj paczkę portable StreamDeck.WindowsAgent-win-x64.zip do osobnego katalogu i uruchom StreamDeck.WindowsAgent.exe. Nie nadpisuj plików pracującego Agenta.

## Firmware

Firmware dotyczy ESP32-2432S028R z potwierdzonym ST7789, landscape320×240. Nie wgrywaj go na wariant ILI9341. Paczka firmware-ST7789-1.1.0.zip zawiera obraz aplikacji oraz obraz scalony do pierwszego wgrania. Aktualizacja istniejącego układu partycji CYD-DECK OTA: aplikacja firmware-ST7789-1.1.0.bin na adres0x10000 przez esptool lub dotychczasowy proces ArduinoOTA. Pierwsza instalacja: scalony obraz firmware-ST7789-1.1.0-full.bin na0x0. Nie używaj erase_flash, jeśli chcesz zachować ustawienia. Aktualizuj Agent i firmware razem, aby obsługiwały nowe cover.request.

## Zmiany

- Cache SD steruje pobieraniem okładek po USB: transfer tylko na cache miss, poprawne baseline JPEG i zaokrąglone narożniki.
- Usunięte pętle hello i błędny timeout USB; discovery/WebSocket zawieszane przy sterowaniu po kablu.
- Timeline wyliczany lokalnie i odświeżany co100ms; skala paska0..10000.
- Mniejszy suwak, poprawna ikona Mute, brak cofania uchwytu przez stare potwierdzenia Windows.
- Top nav bez gestów swipe; brak auto-dim i screen-off podczas aktywnego połączenia z Agentem.
- Poprawki SMTC/CoreAudio, pełna synchronizacja konfiguracji, reaktywna telemetria i odświeżanie widoków.
- Uporządkowany interfejs Windows, edycja/przenoszenie skrótów i podgląd rzeczywistych slotów.
- Maskowanie sekretów w logach, poprawne przywracanie ukrytego okna, instalator per-user i portable self-contained.

## Weryfikacja

Protocol80/80 PASS, pełne WindowsAgent smoke PASS; C++ layout/timeline/USB i glify Mute PASS. Build Agenta i firmware bez ostrzeżeń. Fizyczny CYD: USBconnected, SDready, okładka Available/rendered=true. Kontrolny restart z ciepłym cache:0transferów USB, stabilne heartbeat i brak wzrostu discovery. Użytkownik potwierdził działanie. Wydanie1.1.0 dodaje wersjonowanie i pakowanie; działający na komputerze użytkownika Agent pozostaje uruchomiony z poprzedniego katalogu testowego.

## Odtwarzanie wydania

    powershell -ExecutionPolicy Bypass -File scripts/publish-windows-agent.ps1 -OutputDirectory <repo>/artifacts/release-v1.1.0
    powershell -ExecutionPolicy Bypass -File scripts/build-windows-installer.ps1 -Version 1.1.0 -OutputDirectory <repo>/artifacts/release-v1.1.0 -SkipPublish -IsccPath <InnoSetup>/ISCC.exe
    powershell -ExecutionPolicy Bypass -File scripts/build-firmware.ps1 run -e cyd28_st7789_app -j 8

Zależności i licencje wersji portable znajdują się w THIRD-PARTY-NOTICES. SHA256SUMS.txt obejmuje wszystkie dołączone pliki wydania. Firmware nie zawiera danych Wi-Fi ani tokenu z NVS użytkownika.
