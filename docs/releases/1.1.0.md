# CYD-DECK 1.1.0

## Windows Installation

Download `CYD-DECK-Setup-1.1.0-win-x64.exe` from this release. The per-user installer includes the .NET runtime, graphics libraries, and dependencies. Default directory: `%LOCALAPPDATA%\Programs\CYD-DECK`. Creates a Start Menu entry with an optional desktop shortcut. Uninstallation preserves configuration, pairing, and caches.

Portable alternative: Extract `StreamDeck.WindowsAgent-win-x64.zip` into any directory and launch `StreamDeck.WindowsAgent.exe`.

## Firmware

Firmware is specifically tailored for the **ESP32-2432S028R** with the **ST7789** display controller (320x240 landscape).
- **Updating existing device**: Flash `firmware-ST7789-1.1.0.bin` at offset `0x10000` via `esptool` or OTA.
- **Clean install on a new board**: Flash `firmware-ST7789-1.1.0-full.bin` at offset `0x0`.

## Release Highlights

- **MicroSD Cover Art Caching**: Cover art transfers over USB only on cache miss, eliminating redundant transfers.
- **USB Responsiveness**: Removed redundant handshake loops; background discovery pauses during active USB wire communication.
- **Timeline Interpolation**: Track seek position calculated locally and refreshed every 100 ms on a 0..10000 progress scale.
- **Refined Navigation & Controls**: Smaller volume slider, dedicated Mute icon, top dock navigation without swipe interference, and prevention of screen sleep during active host connection.
- **SMTC & CoreAudio Improvements**: Bidirectional media telemetry, volume synchronization, and responsive UI view updates.
- **Security & Packaging**: Masking sensitive pairing credentials in logs, per-user Inno Setup installer, and self-contained portable package.

## Verification

Protocol 80/80 PASS, full WindowsAgent smoke PASS, native C++ layout/timeline tests PASS. Verified on physical ESP32-2432S028R ST7789 hardware.
