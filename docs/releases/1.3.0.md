# CYD-DECK 1.3.0

CYD-DECK 1.3.0 introduces major enhancements to usability, connection reliability, and installation. It brings an official **browser-based Web Serial installer** hosted via GitHub Pages (1-click flashing without programming tools), a redesigned Windows system tray context menu with direct media controls, native Windows 11 DWM immersive dark mode, a modern HEX/RGB color picker, multi-port USB fault tolerance, and precision PC hardware metrics.

---

## 1. Installation Methods

### A. Online Browser Web Installer (Recommended for CYD)
You do not need to install Python, PlatformIO, or drivers:
1. Open the [CYD-DECK Web Installer](https://blankeuuu.github.io/cyd-deck/web-installer/) in **Google Chrome**, **Microsoft Edge**, or **Brave** on desktop.
2. Connect your **CYD ESP32-2432S028R** board to your PC using a micro-USB data cable.
3. Click **Install Firmware**, select the detected COM port (e.g., *CH340* or *CP2102*), and click **Connect**.
4. Flashing completes in ~30 seconds, after which the device automatically reboots into the new interface.

### B. Windows Agent Installer (`CYD-DECK-Setup-1.3.0-win-x64.exe`)
Download the installer from this GitHub Release.
- **Per-user installation**: Installs into `%LOCALAPPDATA%\Programs\CYD-DECK` without requiring administrator privileges.
- **Self-contained bundle**: Includes the .NET 10 runtime, SkiaSharp graphic dependencies, and all required libraries.
- **Clean uninstallation**: Registered in Windows *Settings > Apps > Installed apps*. The uninstaller automatically terminates any active background tray instance, cleans up autostart entries, and removes all application files cleanly without file-in-use errors.
- A portable package (**`StreamDeck.WindowsAgent-win-x64.zip`**) is also available.

### C. Command Line Flashing via `esptool.py`
- **Application upgrade** (preserves NVS, Wi-Fi credentials, and pairing):
  ```bash
  esptool.py --chip esp32 --port COM5 --baud 460800 write_flash -z 0x10000 firmware-ST7789-1.3.0.bin
  ```
- **Clean install on a new board** (from address `0x0`):
  ```bash
  esptool.py --chip esp32 --port COM5 --baud 460800 write_flash -z 0x0 firmware-ST7789-1.3.0-full.bin
  ```

## 2. Changelog

### Windows Agent
- **System Tray Media Controls**:
  - Live track metadata preview: `🎵 {Title} · {Artist}` directly in the system tray context menu.
  - Quick player actions: Play/Pause, Previous Track, Next Track, and Mute/Unmute toggle.
  - Windows balloon notifications (`BalloonTip`) on device connection (USB/Wi-Fi) and cable disconnection.
  - Updated tray icon branding and tooltip: `CYD-DECK ({DeviceName}) - {Status}`.
- **Modern Color Picker (`ModernColorPickerDialog`)**:
  - Replaced legacy system dialog with a custom dark-mode color picker.
  - Live color preview, hex code entry (`#RRGGBB`), RGB sliders with validation, and quick accent presets.
- **Windows 11 DWM Immersive Dark Mode**:
  - Modal dialog titlebars (`ShortcutEditorDialog`, `ShortcutIconPicker`, `ModernColorPickerDialog`) render with native DWM dark styling and Windows 11 rounded corners.
- **Hotkey Combination Clearing**:
  - Added a dedicated `Clear` button in the shortcut editor to reset recorded keystrokes.
- **USB Fault Tolerance & Disconnect Handling**:
  - `UsbDeviceRuntime`: Probing multiple COM ports gracefully bypasses busy/denied ports (`UnauthorizedAccessException`) and continues testing remaining candidate ports.
  - `SerialPortUsbDuplexStream`: Safely catches sudden cable disconnections during read/write loops without unhandled exceptions.
- **Architecture**:
  - Removed deprecated local HTTP dashboard server (`LocalDashboardServer`), optimizing memory and startup overhead.

### CYD Firmware (ESP32 / LVGL 9.3)
- **On-Device Settings Overhaul**:
  - Intuitive categorized settings under the gear icon: *Display & Brightness*, *Device & Status*, *Touch Calibration*, *System & Power*.
  - Protected destructive actions (*Factory reset*, *Restart*) against accidental taps.
- **PC Resource Metrics**:
  - Support for aggregated GPU engine utilization (integrated and discrete) via Windows PDH.
  - Display RAM usage in both megabytes and percentage.
- **Media Player**:
  - Improved album cover corner clipping (12 px radius) for native 128x128 artwork.
  - Smooth playback timeline with local 100 ms time interpolation.
- **Dock Navigation**:
  - Persistent clock display (`HH:mm`) on the first navigation button synchronized with host PC time.

### Bug Fixes
- **Bearer Token Format Fix (Crypto Flakiness)**: Fixed a rare Base64URL parsing rejection in `ProtocolSerializer` and `PairingApprovalService` for randomly generated tokens starting with `-` or `_`.
- **Atomic Disk Persistence**: Added `Flush(flushToDisk: true)` and retry loops on pairing database reads, eliminating file system race conditions.
- **Installer Dependency Metadata**: Added missing license notice entry for `System.Management 10.0.0` in `publish-windows-agent.ps1`.
- **Host Test Toolchain Resolution**: Resolved native test compiler discovery across PowerShell execution environments.
