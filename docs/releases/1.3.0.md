# CYD-DECK 1.3.0 — Wydanie oficjalne

Wydanie **CYD-DECK 1.3.0** to duży krok naprzód w ergonomii, stabilności i łatwości instalacji docka biurkowego ESP32 oraz powiązanej aplikacji Windows. Wprowadzono oficjalny **przeglądarkowy instalator Web Serial** (1-kliknięcie bez instalacji narzędzi programistycznych), nowo zaprojektowane menu zasobnika systemowego Windows z szybkim sterowaniem mediami, natywny Windows 11 DWM Immersive Dark Mode, nowoczesny selektor kolorów HEX/RGB, uodpornienie komunikacji USB na błędy portów oraz precyzyjne odczyty sprzętowe PC.

---

## 1. Metody instalacji

### ⚡ A. Przeglądarkowy Web Installer (Rekomendowany dla CYD)
Nie musisz instalować Pythona ani PlatformIO, aby wgrać firmware:
1. Podłącz płytkę **CYD ESP32-2432S028R** przewodem USB do komputera.
2. Uruchom skrypt lokalnego instalatora:
   ```powershell
   powershell -ExecutionPolicy Bypass -File scripts/launch-web-flasher.ps1
   ```
3. W przeglądarce (Google Chrome, Microsoft Edge, Brave) kliknij **⚡ Zainstaluj CYD-DECK**, wskaż wykryty port szeregowy i wybierz instalację.
4. Płytka zostanie sflashowana w kilkadziesiąt sekund, zachowując istniejące ustawienia Wi-Fi i parowania w pamięci NVS.

### 💻 B. Instalator Windows Agent (`CYD-DECK-Setup-1.3.0-win-x64.exe`)
Pobierz instalator Windows z wydania GitHub.
- **Instalacja per-user**: instaluje się w `%LOCALAPPDATA%\Programs\CYD-DECK`, nie wymaga praw administratora.
- **Kompletny pakiet**: zawiera runtime .NET 10, silnik SkiaSharp oraz wszystkie biblioteki zależne.
- **Czysta deinstalacja**: zarejestrowany w systemowym aplecie *Aplikacje i funkcje* (Windows Settings). Podczas odinstalowania automatycznie zamyka działającego Agenta z zasobnika, usuwa klucze autostartu i czyści pliki programu bez błędów blokowania.
- Opcjonalnie dostępna jest paczka **`StreamDeck.WindowsAgent-win-x64.zip`** dla instalacji bezinstalacyjnej (portable).

### 📟 C. Ręczna instalacja firmware przez `esptool`
- **Aktualizacja aplikacji** (zachowuje NVS, Wi-Fi i parowanie):
  ```powershell
  esptool.py --chip esp32 --port COM5 --baud 460800 write_flash -z 0x10000 artifacts/release-v1.3.0/firmware-ST7789-1.3.0.bin
  ```
- **Czyste wgranie na nowy moduł** (od adresu `0x0`):
  ```powershell
  esptool.py --chip esp32 --port COM5 --baud 460800 write_flash -z 0x0 artifacts/release-v1.3.0/firmware-ST7789-1.3.0-full.bin
  ```

## 2. Szczegółowy wykaz zmian (Changelog)

### 🪟 Windows Agent
- **Sterowanie multimediami w zasobniku (Tray UX)**:
  - Aktualny podgląd odtwarzanego utworu i wykonawcy: `🎵 {Title} · {Artist}` bezpośrednio w menu kontekstowym tray.
  - Szybkie kontrolki: `▶ Play` / `⏸ Pause`, `⏮ Previous Track`, `⏭ Next Track` oraz przełącznik `🔊 Mute / Unmute`.
  - Powiadomienia balonowe systemowe (`BalloonTip`) o podłączeniu urządzenia po USB lub Wi-Fi oraz o rozłączeniu kabla.
  - Odświeżony branding tooltipa ikony w zasobniku: `CYD-DECK ({DeviceName}) - {Status}`.
- **Nowoczesny Color Picker (`ModernColorPickerDialog`)**:
  - Zastąpiono przestarzały dialog systemowy zaawansowanym oknem dostosowanym do ciemnego motywu.
  - Podgląd koloru na żywo, wprowadzanie kodów szesnastkowych HEX (`#RRGGBB`), suwaki RGB z walidacją oraz paleta szybkich akcentów.
- **Windows 11 DWM Immersive Dark Mode**:
  - Paski tytułowe okien dialogowych (`ShortcutEditorDialog`, `ShortcutIconPicker`, `ModernColorPickerDialog`) renderują się z natywnym ciemnym motywem DWM (atrybut 20) oraz zaokrąglonymi rogami Windows 11 (atrybut 33).
- **Czyszczenie skrótu klawiszowego**:
  - Dodano dedykowany przycisk `Clear` obok pola docelowego skrótu klawiaturowego w edytorze kafelka.
- **Uodpornienie komunikacji USB**:
  - `UsbDeviceRuntime`: Próbkowanie wielu portów COM nie przerywa działania po napotkaniu zajętego portu (`UnauthorizedAccessException`), lecz płynnie przechodzi do kolejnych kandydatów.
  - `SerialPortUsbDuplexStream`: Bezpieczna obsługa nagłego odłączenia przewodu USB w pętli odczytu i zapisu bez niekontrolowanych wyjątków.
- **Architektura**:
  - Usunięto przestarzały, zbędny lokalny serwer HTTP dashboardu (`LocalDashboardServer` i `DashboardHtml`), optymalizując zużycie pamięci i upraszczając architekturę.

### 📟 Firmware CYD (ESP32 / LVGL 9.3)
- **Przebudowa strony ustawień (CYD Settings Overhaul)**:
  - Intuicyjne kategorie ustawień w menu pod kołem zębatym: *Display & Brightness*, *Device & Status*, *Touch Calibration*, *System & Power*.
  - Zabezpieczenie operacji destrukcyjnych (*Factory reset*, *Restart*) przed przypadkowym dotknięciem.
- **Monitor zasobów PC (PC Metrics)**:
  - Wsparcie dla agregowanych silników graficznych GPU (zintegrowanych i dedykowanych) z Windows PDH.
  - Prezentacja zużycia pamięci RAM w megabajtach oraz procentach.
- **Odtwarzacz multimedialny**:
  - Poprawione przycinanie rogów okładki albumu (clip corner radius 12 px) dla natywnego rozmiaru 128×128.
  - Stabilna oś czasu z lokalną interpolacją czasu (odświeżanie co 100 ms).
- **Zegar doku**:
  - Pierwszy przycisk nawigacyjny stale prezentuje aktualny czas `HH:mm` zsynchronizowany z zegarem systemowym PC.

### 🐛 Naprawione błędy
- **Naprawa formatu tokenów parowania USB (Crypto Flakiness)**: Wyeliminowano rzadki błąd formatu tokenu Base64URL w `ProtocolSerializer` i `PairingApprovalService`, który odrzucał losowo wygenerowane tokeny rozpoczynające się od znaków `-` lub `_`.
- **Wymuszenie zapisu na dysk**: Dodano `Flush(flushToDisk: true)` oraz pętlę ponawiania przy odczycie bazy parowania, eliminując wyścigi dyskowe w testach i na Windows.
- **Obsługa zależności w skrypcie instalatora**: Dodano brakujący wpis manifestu licencyjnego dla `System.Management 10.0.0` w `publish-windows-agent.ps1`.
- **Obsługa kompilatora testów hosta**: Naprawiono błąd `UnauthorizedAccessException` w `scripts/test-ui-logic.ps1`, `render-ui-preview.ps1` i testach kalibracji.

## 5. Odtwarzanie wydania ze źródeł

```powershell
# 1. Zbudowanie paczek Windows i instalatora Inno Setup
powershell -ExecutionPolicy Bypass -File scripts/build-windows-installer.ps1 -Version 1.3.0

# 2. Zbudowanie firmware ST7789
powershell -ExecutionPolicy Bypass -File scripts/build-firmware.ps1 run -e cyd28_st7789_app -j 8

# 3. Scalenie pełnego obrazu firmware (0x0)
.tools/pio-venv/Scripts/python.exe .tools/platformio-core/packages/tool-esptoolpy/esptool.py --chip esp32 merge_bin -o artifacts/release-v1.3.0/firmware-ST7789-1.3.0-full.bin --flash_mode dio --flash_freq 40m --flash_size 4MB 0x1000 .pio-app/cyd28_st7789_app/bootloader.bin 0x8000 .pio-app/cyd28_st7789_app/partitions.bin 0xe000 .tools/platformio-core/packages/framework-arduinoespressif32/tools/partitions/boot_app0.bin 0x10000 .pio-app/cyd28_st7789_app/firmware.bin
```
