# CYD-DECK 1.2.0

## Windows Installation

Download `CYD-DECK-Setup-1.2.0-win-x64.exe` from this release. The per-user installer bundles the .NET 10 runtime, SkiaSharp graphic dependencies, and all required libraries—no external .NET installation is required.
Default directory: `%LOCALAPPDATA%\Programs\CYD-DECK`.
Creates a Start Menu entry with an optional desktop shortcut. Uninstallation preserves configuration, pairing, and cached artwork and icons.

Portable alternative: Extract `StreamDeck.WindowsAgent-win-x64.zip` into any folder and launch `StreamDeck.WindowsAgent.exe`.

## Firmware

Firmware is specifically tailored for the **ESP32-2432S028R** with the **ST7789** display controller (320x240 landscape).
- **Updating existing device**: Flash `firmware-ST7789-1.2.0.bin` at offset `0x10000` using `esptool` or the OTA update mechanism in the Agent. Do not use `erase_flash` to preserve Wi-Fi credentials and NVS pairings.
- **Clean install on a new board**: Flash `firmware-ST7789-1.2.0-full.bin` at offset `0x0`.

## Release Highlights

- **Centered Buttons & Labels on CYD**:
  - Home screen shortcut tiles (148x44) dynamically group and center the icon and text horizontally and vertically, eliminating asymmetrical spacing.
  - Deck/Shortcuts grid layouts (6, 4, 2, and 1 tiles) center label text symmetrically beneath the button icon.
- **Visual Icon Picker & URL Image Import**:
  - 21 vector icons built into the dedicated `cyd_icons_20` font.
  - Direct download and decoding of PNG/JPEG images from URLs into RGB565A8 format (24x24 px, 1728 bytes) with alpha transparency via SkiaSharp.
  - NVS v3 binary icon pixel caching with LVGL image cache invalidation on revision changes.
- **Windows Agent 1.2.0**:
  - New icon picker with live preview, 21-glyph gallery, and URL graphic import field.
  - Explicit Save and Save & Sync workflows preventing unsaved configuration loss.
  - Comprehensive unit and integration test coverage for imports and protocol sessions.

## Verification

All .NET unit tests (`StreamDeck.WindowsAgent.Tests`) and native C++ host tests (`test-ui-logic.ps1`) pass. Verified on physical ESP32-2432S028R ST7789 hardware on COM5.
